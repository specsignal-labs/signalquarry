# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. In short: be respectful, assume good faith, and keep discussion
about the work. Harassment and personal attacks are not tolerated.

Report conduct concerns privately to the maintainer through a GitHub security
advisory on this repository (it is private) or the contact on the maintainer's
GitHub profile. Reports are handled confidentially.
