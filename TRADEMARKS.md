# Name and logo use

The Apache-2.0 license covers the code, not the project's names (Apache-2.0,
section 6). "SignalQuarry" identifies this project and its maintainer.

You may use the name to refer to the project truthfully, for example "built with
SignalQuarry" or "a SignalQuarry plugin". Please do not use it as the name of
your own product or fork, or in a way that suggests endorsement by or affiliation
with the maintainer. Forks should choose a different name.

Questions: open an issue.
